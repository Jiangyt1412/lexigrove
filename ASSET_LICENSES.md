# Original pixel habitat assets

These SVG assets were created from new integer-grid geometry for this project by Codex. They use no downloaded artwork, traced illustrations, external sprite libraries, or recognizable assets from an existing game. The limited palette and general pixel-art technique are common visual conventions.

## Files and usage

- `garden-base.svg`: 1100 × 340, viewBox 550 × 170. Eight empty crop beds. Exact bed and sprite anchors are recorded in `manifest.json`.
- `aquarium-base.svg`: 700 × 300, viewBox 350 × 150. Clear central water column; no fish or coral baked into the scenery.
- `sprites.svg`: reusable SVG symbols, all viewBox 0 0 32 32.
- `blue-horizon.svg`: original 720 × 280 underwater scenery, explorer, rock shelves and coral; decorative fish are not earned aquarium residents. The user's requested DAVE THE DIVER ocean mood informed the new palette; no game art was downloaded, copied or traced. Reference: [MINTROCKET official press kit](https://pressmintrocket.oopy.io/dave_the_diver).
- `ocean-tiles.svg`: original repeating 128 × 128 staircase mosaic for the shell and full-screen study scene.
- `world-life.svg`: 13 new reusable 32 × 32 symbols: bird, butterfly, bee, duck, frog, cat, fish, reef-fish, shrimp, crab, lantern, watering can and book. The seasonal garden/aquarium uses these independently positioned symbols.

The older living environments are composed in `src/world/LivingScene.tsx` on a 640 × 320 integer grid. Scene geometry, seasonal variations and CSS motion are project-original application code under MIT; the standalone SVG files retain their CC0 dedication. The new continuous village is composed in `src/world/CoastalWorld.tsx` with original scene-only coastal WebP art and independent SVG plants, creatures, water and actual HTML controls. The learning room and journal use the same visual direction. Original generated coastal assets have the same CC0 dedication to the extent rights apply; no reference-image pixels or commercial-game sprites are redistributed. [docs/COASTAL_ART.md](docs/COASTAL_ART.md) records the built-in image generation prompts, selected files and hashes. The older base scenes and marine decorations remain available but are not the new home hero. `manifest.json` inventories files that actually exist, with XML checks and hashes generated by `scripts/audit_original_assets.py`; it does not claim nonexistent standalone sprite files or exhaustive visual validation.

Keep integer scaling when possible and use `image-rendering: pixelated`. The SVG geometry itself also specifies `shape-rendering="crispEdges"`. Reward objects should be placed independently according to genuine application progress. The background is decorative only.

Main headings, navigation and world controls use pixel typography. All learning text and the entire dictionary, including its action buttons, part of speech and IPA, use regular readable sans-serif. System fallback fonts are requested from the user's platform and are not copied or bundled by the application.
